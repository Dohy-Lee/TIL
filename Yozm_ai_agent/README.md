# 요즘 AI 에이전트 개발

『요즘 AI 에이전트 개발』(박승규 저, 골든래빗)을 학습하며 핵심 개념과 실습 내용을 정리한 저장소

**LLM API**, **LangChain**, **AI Agent**, **LangGraph**, **MCP / A2A**를 중심으로 학습하며, 책의 예제(약 60가지)를 직접 구현하고 관련 개념을 정리

또한 학습한 내용을 기반으로 향후 싱글 에이전트 및 멀티 에이전트 시스템 프로젝트를 개발하기 위한 기초를 다지는 것이 목표

---

## 학습 기간

- 시작일 : 2026.07.20
- 종료일 : 진행 중

---

## 학습 목표

- LLM API의 기본 구조와 스트리밍 / 비동기 / 오류 핸들링 이해
- 랭체인의 핵심 콘셉트(Runnable, LCEL, Tool, 임베딩, 벡터 스토어, RAG) 이해
- 에이전트의 구조와 Tool Calling, 가드레일, 핸드오프 이해
- 랭그래프의 그래프 기반 워크플로(조건부 라우팅, 체크포인터, 병렬 처리, 휴먼 인 더 루프) 이해
- MCP와 A2A 등 최신 에이전트 프로토콜의 동작 원리 이해
- 예제 코드를 직접 구현하며 실습 경험 축적
- 향후 멀티 에이전트 프로젝트 개발을 위한 기반 구축

## 학습 방법

『요즘 AI 에이전트 개발』의 모든 챕터를 순차적으로 학습 

- AI Agent (Agents SDK / ADK)
- LangGraph
- MCP / A2A
- RAG

각 챕터를 학습하며 다음 내용을 정리

- 코드 내 모르는 함수나 메소드 정리
- 학습하면서 개념 정리
